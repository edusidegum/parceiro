# Ecossistema Parceiro — edusidegum.github.io/parceiro/

Ecossistema de captação digital com 20 landing pages temáticas + HUB central + página de cadastro,
desenvolvido para Eduardo Sidegum — Distribuidor Independente Herbalife.

## Estrutura
- `index.html` — HUB central (prospecto decide o caminho)
- `evs-digital/ … oportunidade-autonomia/` — 20 landing pages de atração (SEO/GEO/AEO/AIO)
- `cadastro/cadastro.html` — página final de conversão (cópia estrita, indexável)
- `assets/` — `css/style.css`, `js/bloco-incluir.js`, `js/bloco-protecao.js`, `img/`
- `robots.txt`, `sitemap.xml`, `404.html`, `BingSiteAuth.xml`, `google82b0e011e22c61ab.html`, `politica.html`

## Compliance
- Distribuidor Independente Herbalife — página em conformidade com o Manual de Normas (BR, Rev. 2025)
- Sem promessa de ganhos, sem claim de saúde, sem divulgação pública de preços
- LGPD: consentimento explícito (banner) antes de GA4/GTM; política em `politica.html`
- Catálogo oficial auditado: https://catalogoherbalife.com.br/edusidegum

## Rastreamento
Substitua `SEU_GTM_ID` e `SEU_GA4_ID` em `assets/js/bloco-incluir.js` (constantes no topo).

## Performance
PageSpeed alvo > 90. Fontes nativas, WebP, hero LCP com fetchpriority, JS defer, CLS < 0.1.
